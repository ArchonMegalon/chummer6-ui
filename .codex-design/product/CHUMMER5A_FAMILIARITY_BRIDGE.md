# Chummer5a Familiarity Bridge

Parity is the default bridge for any route that already existed in Chummer5a.

Bridge rules:

- keep the same mouse-first outcome with the least possible relearning
- preserve widget class, option posture, event parity, dependent updates, validation, and commit behavior
- do not replace editable legacy routes with snippets, fact cards, review expanders, or prose
- keep the same geography when geography carried workflow meaning
- allow divergence only when the Chummer6 design explicitly authorizes it
- new flagship additions must layer on top of familiarity instead of displacing it

Examples of allowed Chummer6 additions:

- structured feedback and crash entry points
- source-linked explain drawers and receipts
- Build Ghost compare benches
- explicit ruleset and restore posture warnings
