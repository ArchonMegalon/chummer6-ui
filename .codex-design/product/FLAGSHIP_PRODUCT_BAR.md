# Flagship Product Bar

The flagship product is not complete because the route opens.
It is complete only when the promoted desktop head behaves like a premium expert workbench.

Required bar:

- startup lands on the real workbench, not a synthetic dashboard detour
- no self-termination after first paint
- SR4, SR5, and SR6 each get authored UI depth appropriate to their ruleset
- legacy-overlapping routes preserve recursive parity by default
- Chummer6-specific additions such as feedback, crash entry, Build Ghost, and source-aware explain are first-class surfaces, not hidden utilities
- dense workbench posture beats review chrome on editing routes
- every release-blocking gate fails closed on missing runtime materialization, missing event wiring, or unsupported-state dishonesty

This bar is release-blocking.
